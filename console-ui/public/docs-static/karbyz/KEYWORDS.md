# Словарь языка Карбыз

Нормативный перечень — спецификация §2.6 (документ 1.4).

## Типы и константы

| Обозначение | Перевод | Что хранит / роль |
|-------------|---------|-------------------|
| сан | число | целое со знаком (≥32 бит) |
| суз | слово / строка | Unicode-строка |
| тезма | ряд / массив | упорядоченный список, индекс с 0 |
| логик | логический | boolean: `дорес` или `ялган` |
| дорес | истина | литерал `логик` / константа |
| ялган | ложь | литерал `логик` / константа |

## Структура и связывание

| Обозначение | Перевод | Роль |
|-------------|---------|------|
| жыелма | собрание / модуль | единица компиляции |
| ахыр | конец | закрытие блока / модуля |
| :: | открыть блок | начало составного оператора |
| <- | присвоить | связывание значения с именем |

## Управление потоком

| Обозначение | Перевод | Роль |
|-------------|---------|------|
| агар | если | условие |
| булса | то | ветвь then |
| юкса | иначе | ветвь else |
| шулай | пока так | while |
| вакыт | время / пока | хвост while |
| очен | для | for |
| да | и / до | зона for |
| кадак | шаг | зона for |
| кайтар | вернуть | return |

## Объявления и I/O

| Обозначение | Перевод | Роль |
|-------------|---------|------|
| эшлама | работа / функция | объявление функции |
| керт | ввести | stdin (`сан`/`суз`/`логик`) |
| чыгар | вывести | stdout |
| озынлык | длина | длина суз или тезма → сан |

## Логика

| Обозначение | Перевод | Роль |
|-------------|---------|------|
| хам | и | логическое И → `логик` |
| яки | или | логическое ИЛИ → `логик` |
| тугел | не | логическое НЕ → `логик` |
